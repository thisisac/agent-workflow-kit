# Changelog

## 0.3.4-alpha — 2026-11-11

- Added goal-driven skill discovery and task-local adaptation for concrete capability gaps, with source/compatibility checks and bounded searches.
- Added a workflow evolution method: diagnose the cause, isolate a candidate, compare old/new behavior and regressions, then adopt or roll back at an attempt boundary.
- Documented settings, authorization scopes, stable active revisions and retained costs. Host tools implement discovery, edits and evaluation; the runtime has no automatic installer or hot-swap API.
- Added five unrun behavior specifications for skill selection and evolution. Existing runtime code and interfaces are unchanged; no measured model-behavior improvement is claimed.

## 0.3.3-alpha — 2026-11-11

- Reorganized both READMEs around purpose, one practical task, workflow, monitoring and integration choices; moved implementation detail into dedicated guides.
- Expanded architecture documentation with module inputs/outputs, evidence handoffs, review versus verification, state storage and a complete call lifecycle.
- Added a monitoring guide covering host responsibilities, setup, live-job observation, asynchronous limits, reconciliation and notification handling.
- Expanded runnable-demo output and callback integration instructions. Runtime code, skill instructions and behavior specifications are unchanged from 0.3.2.

## 0.3.2-alpha — 2026-11-11

- Broadened the skill from long-task continuation to research and iterative project improvement, including single-cycle work.
- Made targeted project inspection and external retrieval available during planning, review and reflection, with source-to-claim records and private-query boundaries.
- Specified pre-execution scientific merit, feasibility and acceptance review separately from post-execution result verification.
- Added a research/optimization prompt, a synthetic optimization walkthrough and three unrun evaluation cases. Module instructions changed; runtime engine and interfaces are unchanged.

## 0.3.1-alpha — 2026-11-11

- Rewrote English and Chinese READMEs around installation, a concrete task, continuation, observable demo outputs, configuration and recovery.
- Replaced the product proposal with architecture documentation grounded in the shipped components, callback interfaces and state transitions.
- Updated skill discovery and UI descriptions to describe the research/execute/verify/reflect loop.
- Used GitHub awesome-copilot create-readme and reviewed comparable skill READMEs; upstream snapshots remain outside the public package. Runtime behavior is unchanged from 0.3.0-alpha.

## 0.3.0-alpha — 2026-11-11

- Added explicit routine effort for known cheap reversible work: plan, execute, verify; all acceptance and scope checks remain. Deliberate is still the default.
- Folded continuation into the reflection transaction; continue reuses research and pivot opens a new question. No RESUME host callback is needed.
- Limited workspace tree scans to launch admission; preserved lightweight resource checks and launch-time rechecking.
- Reduced repeated entrypoint instructions and documented the necessity audit, defaults, required ceilings and tuning boundaries.
- Added synthetic tests for compact routing, escalation, research reuse and retained safety; no model efficacy or real-world savings claim.

## 0.2.0-alpha — 2026-11-11

- Added seven module contracts: research/learn, plan, plan review, execution, result verification, reflection and continuation.
- Added an original SQLite reference runtime with durable claims, scope precedence, resource admission, duplicate/plateau checks, explicit reconciliation and bounded lesson memory.
- Added an actual optional LangGraph router and provider-neutral reasoning bridge; execution and verification remain separate trusted callbacks. No Deep Agents connector or model behavior result is claimed.
- Added a POSIX local process adapter with group timeout, bounded retained logs and command-bound receipts.
- Added synthetic restart, concurrency, crash, control, identity, accounting and graph integration tests plus a runnable three-cycle demo.
- Kept public files separate from private evidence, actual data and execution workspaces; expanded release membership only for original reference-runtime code.

## 0.1.3-alpha — 2026-11-10

- Distinguished current user scope from executor phase: planning-only instructions and pauses override historical continuation/readiness.
- Added email-address rejection to public-file checks and the existing synthetic rejection test.
- Documented release-only staging for public repositories, excluding private authoring files and history.
- Local operational adapters and observations remain outside this package; no runtime or behavioral efficacy claim is added.

## 0.1.2-alpha — 2026-11-10

- Added guidance for improving an existing field workflow and distinguishing operational evidence, retrospective findings, reproductions, and measured skill improvement.
- Clarified attempt-scoped state, changing records, stale instructions, and compact read-only views that retain original evidence.
- Added a synthetic training walkthrough and two evaluation specifications for conflicting state and existing private field cases. No private field records or code are distributed.
- Kept model evaluation unrun; field inspection is not a controlled skill comparison.

## 0.1.1-alpha — 2026-11-10

- Compared pinned authoring, evaluation, and maintenance guidance from planning-with-files, Superpowers, Compound Engineering, and Anthropic's skill-creator.

At 0.1.1 no controlled agent comparison or runtime recovery test had been completed. Later synthetic runtime tests are documented separately; no version establishes improved agent task success or production reliability.
